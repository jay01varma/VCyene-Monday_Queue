# LILA support desk
From the repository root, run `python3 -m http.server 8000 --directory dist` and open http://localhost:8000. No install or build. Stop with Ctrl+C.
The desk always represents Monday, October 5, 2026. Business days are Monday–Friday. Deadline dates use delivery plus 14 or 30 calendar days. The source of the initial queue is dist/tickets.csv. Browser-local edits are private to the current browser profile and origin. The demo has no mail server. Use **Email customer** in a ticket to write a reply: it checks the address, then opens your email app with the message prefilled (a `mailto:` link). After you send it there, choose **Log as sent** to add the email to the case notes and mark support as having replied, which clears any reply-due flag. The customer's address is remembered for that ticket in this browser.
To change priorities during a walkthrough, edit priority() in dist/rules.js, save and refresh. Run the rule checks with node --test triage.test.js.
